# 更新日志

## 0.9.1 — 首个发布版本

savegame 的首个发布版本——面向 Infernux 引擎的写透式槽位键值存档库：

- **写透默认**——`set` 变化即落盘，崩溃最多丢最后一次已确认的变化；
  批量模式（`batch()` / `flush()`）是高频写入的自选原语。
- **槽位**——隔离的存档空间；编辑器域与 Player 域天然分离。
- **文件即值**——明文 JSON 可开可改；可选槽级压缩与聚合布局，随时经
  `migrate` 切换，`diagnose()` 纯读扫描静默异常。
- **Savegame Browser 编辑器面板**——暂存编辑＋显式确认保存、独立槽位
  浏览、大数据虚拟化渲染。
- **八个 MCP 操作**（`mervingamestudio.savegame.*`），AI agent 免探针
  脚本驱动存档调试。
- 零第三方依赖。要求 Infernux 引擎 0.4.x。
